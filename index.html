SHART OPERATORI

6-sinf uchun informatika darsi -- "Agar... bo'lsa... aks holda..."

1. NAZARIYA

Shart operatori nima?

Shart operatori -- bu dasturga "agar shu holat to'g'ri bo'lsa, shuni qil, aks holda boshqa ishni qil" deb buyruq berish usuli. Kompyuter avval shartni tekshiradi: u yoki TO'G'RI (ha), yoki YOLG'ON (yo'q) bo'ladi.

Hayotdan misol:
Agar chiroq qizil bo'lsa → to'xtaymiz.
Aks holda (ya'ni yashil bo'lsa) → yuramiz.

Yozilishi (sintaksis)

Avval o'zbekcha tilda tushunamiz:

agar (shart) bo'lsa {
    // shart TO'G'RI bo'lganda shu yer ishlaydi
} aks holda {
    // shart YOLG'ON bo'lganda shu yer ishlaydi
}

Haqiqiy dasturlash tilida (JavaScript) xuddi shunday yoziladi:

if (shart) {
  // amallar
} else {
  // amallar
}

Taqqoslash belgilari

BelgiMa'nosi
>katta
<kichik
>=katta yoki teng
<=kichik yoki teng
==teng
!=teng emas

To'liq misol

agar (yosh >= 18) bo'lsa {
    chiqar("Katta odam")
} aks holda {
    chiqar("Bola")
}

Agar yosh = 20 bo'lsa, shart TO'G'RI, demak ekranda "Katta odam" chiqadi.

3. YO'RIQNOMA (O'qituvchi uchun)

  1. Supabase'da loyiha ochish: supabase.com saytiga kiring, ro'yxatdan o'ting va "New Project" tugmasini bosib yangi loyiha yarating.
  2. Jadval yaratish: chap menyudan "SQL Editor" bo'limini oching, bu faylning eng yuqorisidagi HTML izoh ichidagi SQL kodni nusxalab joylashtiring va "RUN" tugmasini bosing. Shu bilan "natijalar" jadvali tayyor bo'ladi.
  3. URL va anon kalitni olish: chap menyudan "Project Settings" → "API" bo'limiga kiring. U yerda "Project URL" va "anon public" kalitini ko'rasiz. Ularni nusxalab, shu faylning SUPABASE_URL va SUPABASE_ANON_KEY o'zgaruvchilariga joylashtiring.
  4. "Row Level Security policy" xatosi chiqsa: bu SQL kodidagi create policy qatorlari ishlamagani yoki jadval RLS yoqilgan holda policy yaratilmaganini bildiradi. SQL Editor'ga qaytib, yuqoridagi SQL kodni to'liq qaytadan ishga tushiring.
  5. Sinab ko'rish: index.html faylini brauzerda oching, mashqlarni bajaring va "Yuborish" tugmasini bosib natija pastdagi ro'yxatda ko'rinishini tekshiring.
